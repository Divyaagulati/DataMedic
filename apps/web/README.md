# DataMedic web app

Next.js 16 (App Router) + TypeScript + Tailwind CSS + shadcn/ui. See the repository
[README](../../README.md) for setup. The browser calls the API directly
(`NEXT_PUBLIC_API_BASE_URL`) with cookies; this app's server holds no dataset data.

Before changing Next.js code, read the bundled docs in `node_modules/next/dist/docs/`
(see `AGENTS.md`): this major version differs from older Next.js releases.
